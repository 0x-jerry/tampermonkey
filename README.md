# Some Useful TamperMonkey Scripts

## Development

```sh
# replace xxx with the script that need to debug
npm run dev -- src/xxx.user.ts
```

**Scripts:**

- **Toggle Theme<sup>1.1.9</sup>**: Very lightweight solution to toggle dark/light theme. [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/toggle-theme.user.js)
- **Un Login<sup>1.0.6</sup>**: Auto close login dialog at some site. [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/un-login.user.js)
- **Simple MMO<sup>1.0.4</sup>**: Try to save the simple mmo world! [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/smmo.user.js)
- **Enhance GitHub<sup>1.0.8</sup>**: Enhance GitHub with useful features like displaying repository size [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/enhance-github.user.js)
- **Enhance GitHub Mermaid Preview<sup>0.0.1</sup>**: Enhance GitHub Mermaid diagrams with drag-to-pan and wheel / pinch zoom gestures [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/github-mermaid-preview.user.js)
- **Un Redirect<sup>1.3.6</sup>**: Skip redirect at some search result page. [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/un-redirect.user.js)
- **Happymh Quick Nav<sup>1.0.7</sup>**: Add convenient buttons to switch chapters [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/happymh.user.js)
- **Eruda<sup>1.0.6</sup>**: Eruda devtool for mobile browser [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/eruda.user.js)
- **Unlock Selection<sup>1.0.7</sup>**: Unlock text selection [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/unlock-selection.user.js)
- **Refine Reading<sup>1.0.5</sup>**: Refine style of hetushu.com [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/refine-reading.user.js)
- **Youtube Background<sup>1.0.3</sup>**: Youtube background player, port from [Youtube-Background](https://github.com/alkisqwe/Youtube-Background) [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/ytb-bg.user.js)
- **WeRead Solarized Theme<sup>1.0.11</sup>**: Change the theme of WeRead [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/weread.user.js)
- **ColaManga Quick Nav<sup>1.0.3</sup>**: Add convenient buttons to switch chapters [install](https://raw.githubusercontent.com/0x-jerry/tampermonkey/refs/heads/gh-pages/colamanga.user.js)
